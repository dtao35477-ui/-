# 险境消消乐 · Relic Rush

原创探险家阿洛的地形救援三消游戏。手机、电脑均可直接在浏览器游玩。

试玩地址：https://dtao35477-ui.github.io/-/rescue/

## 玩法

1. 点击「开始救援」，交换相邻宝物，横向或竖向凑成三个同色。
2. 在石块上下左右的位置完成消除，可以挖开相邻塌方。标记 2 的硬石需要两次冲击。
3. 石块挖掉后宝物落入空位，连锁消除继续挖掘。清掉本关全部石块，阿洛就能逃生。
4. 四连生成十字闪电，五连生成爆破宝物；直接点击特殊宝物可发动。
5. 每次消除都能稍微推迟危险；场景说明中指定的颜色有额外效果。
6. 「找一步」提供空间挖掘提示。暂停、查看说明、离开当前标签页时危险停止。动画结算期间也不会扣时间。

## 使用和开发

- 在线玩：打开上述网址，无需安装、登录或付款。
- 本地预览：在此文件夹运行 `node scripts/serve.cjs`，打开 http://127.0.0.1:4175/ 。
- 规则测试：`node --test tests/engine.test.cjs tests/effects.test.cjs`。
- 原生 HTML / CSS / JavaScript，无运行时第三方依赖。
- `engine.js`：匹配、挖掘、硬石、连消、关卡、胜负。
- `app.js`：操作、音效、语言、暂停和成绩。
- `art.js`：图集、地形、16 帧人物动作、蛇的曲线骨架和 6 帧表情。
- `effects.js`：实际宝物图像碎片、玻璃药液、贝壳珍珠、金星光芒、宝石碎晶、魔法雾气、闪电和爆破。
- `assets/*.webp`：发布使用的五张美术图集，总计约 2.07 MB。

支持中文和英文、鼠标点击、触摸滑动、键盘方向键与 Enter。最好成绩、语言、音效选择仅保存在当前浏览器本地；不保存进行到一半的关卡。清除浏览器数据会清除成绩。

## 美术与参考

角色、宝物、巨石、守卫、遗迹背景均为本项目通过内置图像生成工具生成的素材，未提取参考游戏的代码、角色或图片。人物有 16 帧循环动作，包含眨眼、呼吸、张嘴惊恐、四步奔跑与开心挥手；失败时使用疲惫姿态。第 7 关巨蟒由连续摆动的身体曲线和 6 帧头部表情组成，可以眨眼、吐信、张嘴和后缩。生成提示词见 ART_PROMPTS.md。

参考用户提供的 King Rescue 商店页面及截图，借鉴「消除解救人物、环境危险、地形障碍」这一玩法方向。当前作品是可玩的原创试玩版，尚未做真实玩家留存或商业化验证。
